# V-Taper 30

A 30-day fat-loss, chest-and-back plan for one person in Nanjing: a 6-day push/pull/legs split, a 3D figure that lights up the muscles you train, animated exercise photos, a canteen tray builder, and the research behind each choice.

Live: https://mongolwebstores.github.io/v-taper-30/

- Static site, no build step. Everything (fonts, three.js, images) is hosted in this repo so it loads without Google or third-party CDNs.
- Exercise photos: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense / public domain).
- Food photos: Wikimedia Commons, credited on the page and in `img/food/credits.json` (CC BY / CC BY-SA / CC0).
- three.js r160 (MIT) in `vendor/`. Fonts: Archivo and JetBrains Mono (SIL OFL).

Not medical advice.
